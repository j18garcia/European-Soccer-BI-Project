# Jose Luis — Business Analytics Visualizations

## European Soccer BI | CAP2761C

This folder contains two Excel-based business intelligence visualizations developed using SQL query results from Azure SQL Database.

### JL-V01 — Recurrent Mid-Table Opportunities

**Source:** JL-Q02 — Mid-Table Opportunities

Identifies clubs that repeatedly finished in mid-table positions while performing above their respective league averages.

**Key finding:** Liverpool, Tottenham Hotspur, Southampton, and Everton qualified in three of the five seasons analyzed.

### JL-V02 — Performance Improvement

**Source:** JL-Q04 — Performance Improvement

Compares clubs' points per match (PPM) between the 2011/12 and 2015/16 seasons.

**Key finding:** Atlético Madrid demonstrated the greatest improvement (+0.84 PPM), followed by Villarreal CF (+0.61) and Hertha BSC Berlin (+0.56).

### Files

- JL-V01: Excel workbook and PNG visualization.
- JL-V02: Excel workbook and PNG visualization.

### Business Application

These analyses help identify clubs for preliminary sponsorship and advertising evaluation based on sporting performance. They do not measure financial returns or sponsorship profitability.
